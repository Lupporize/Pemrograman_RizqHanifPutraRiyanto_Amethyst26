# Ringkasan Permasalahan/Problem

**Problem 1 - The Last Astronaut**
Simulasi eliminasi astronot dalam formasi melingkar (varian Josephus Problem) dengan nilai K yang berubah secara dinamis setelah setiap eliminasi, tergantung paritas nomor astronot yang tereliminasi.
 
**Problem 2 - Alien-In-The-Middle**
Program penyandian pesan dengan sistem sandi kustom, di mana setiap huruf digeser berdasarkan nilai posisi alfabet dari huruf asli sebelumnya, dengan wrap-around setelah huruf Z.
